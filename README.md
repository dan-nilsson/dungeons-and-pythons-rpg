## 📝 Description

Python Fundamentals Project focusing on Object-oriented-programming OOP.

## ✨ Features

- ✅ Text based GUI
- ✅ Complex combat system (dodge,parry,critical,armor)
- ✅ Player equipment and inventory
- ✅ Game map with locations
- ✅ Save, Load game state to, from disk

## ⚡ Quick Start

```bash

# 1. Clone the repository
git clone https://github.com/dan-nilsson/dungeons-and-pythons-rpg.git

# 2. Run application in console
/src/ python main.py
```
